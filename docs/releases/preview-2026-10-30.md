Choose one Windows installer. Both require Windows 10 / 11 x64 and are **unsigned**. Android requires 7+ for typed input and uses an **Android debug certificate**. Local dictation needs Android 12+ with an on-device recognition service and language.

The companion needs FRIDAY running on Windows and Python 3.12+ with the attached `companion-requirements.txt` installed. Read **INSTALL.md** before pairing. Windows speech also needs its Python packages; the installer does not install Python.

## Included changes

- Project switches show one selected-project label instead of accumulating labels.
- Project setup accepts custom goals and languages, optional folders and presets, and a saved provider.
- Onboarding saves progress and supports leaving setup to work or open Settings.
- The Android preview includes readable answers, history, reviewed requests, progress, approval previews, cancellation, and receipt-specific undo.
- The desktop includes the opt-in companion gateway, private-network pairing, and optional private Tailscale HTTPS configuration.

## Source and hashes

Use **FRIDAY-preview-2026-10-30-source.zip** for the development source used by these packages. It includes the companion and research changes beyond the tagged documentation commit, a per-file `SOURCE-MANIFEST.json`, and the local Rust speech-wrapper crates with license notices. GitHub's automatic source archives describe the tagged repository commit.

Model weights, Python environments, local settings, credentials, build outputs, and user records are excluded from the source ZIP. Toolchains and speech resources are separate build prerequisites.

**SHA256SUMS.txt** covers every attached file except itself. **release-manifest.json** records package versions, sizes, hashes, source provenance, and verification results. A successful hash comparison establishes file integrity; the Windows packages remain unsigned.
